Zero-trust process harness for AI coding agents

k8s orchestrates compute containers; g8s orchestrates AI agent CLI workers. Private Git worktrees, path-scoped write receipts, and lossless verification firewalls in a single static binary.

Without containment, autonomous agents write anywhere, leak tokens in ambient shells, and leave runaway zombie processes.
write receipt (a single-use cryptographic token that names exactly which files a worker may touch)
CAS lease (a compare-and-swap lock in SQLite WAL that prevents two workers from claiming the same task)
gate lane (a risk-calibrated verification pipeline ranging from fast docs checks to dual-blind security audits)

Ambient shell risk vs zero-trust harness

Why letting autonomous agents execute directly in ambient user shells leads to silent catastrophic failures.

Ambient shell execution Status quo

  • [x]
    Unbounded filesystem authority Workers execute arbitrary commands and can accidentally mutate or delete files outside target modules.
  • [x]
    Orphan zombie processes Child processes survive agent crashes, remaining hidden in background loops and pegging CPU cores at 100%.
  • [x]
    Working tree corruption Failed agent experiments and uncommitted syntax errors directly pollute developer checkout state.
  • [x]
    Context quota flooding Megabytes of raw compiler tracebacks flood the coordinator context window, depleting model quotas.

g8s zero-trust process harness Guaranteed

  • [ok]
    Path-scoped write receipts Mutations require single-use, time-limited capability receipts listing exact allowed file paths.
  • [ok]
    Clean process group termination POSIX process groups (Setpgid) guarantee entire child trees terminate cleanly on timeout or abort.
  • [ok]
    Fail-closed Git worktrees Each task executes in an isolated Git worktree; only verified, accepted changes are delivered.
  • [ok]
    Lossless information firewall Transforms megabytes of raw logs into compact, structured verification receipts for the orchestrator.

Two-axis architecture and containment rings

Physical isolation rings (Axis X) combined with orthogonal control strata (Axis Y) for complete zero-trust delegation.

F0 Brain Tier

Holds exclusive authority over architecture decisions, commit history, and write receipt minting. Never executes untrusted code directly.

Harness Kernel

Pure-Go zero-trust mediator. Manages SQLite WAL task queue, CAS worker leases, reflex triage, and lossless log compaction.

F1 & F2 Workers

Ephemerally spawned in private Git worktrees and POSIX process groups. Mutations strictly bounded by in-process path receipts.
