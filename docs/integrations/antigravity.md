# Google Antigravity (AGY) Integration Guide

`g8s` is a provider-agnostic orchestration and zero-trust containment harness. **Google Antigravity (`agy`)** is supported as one `platform_dispatch` CLI adapter alongside peers such as `opencode`, `codex`, `claude`, `cursor`, and HTTP `api_call` gateways (`9router`, `openai`, `anthropic`, `google`).

---

## 1. How g8s Supervises AGY

When `g8s` executes tasks assigned to Antigravity CLI:
1. `g8s` spawns `agy --print` inside an isolated POSIX Process Group (`Setpgid: true`) within a dedicated git worktree.
2. `g8s` injects the contract prompt generated by `harness.BuildContractPrompt`.
3. If the task is `read_only`, `g8s` monitors for mutation violations via `PostRunScan`.
4. If the task has `workspace_write`, `g8s` verifies that an active Write Receipt was consumed before allowing file edits.
5. `WriteReceipt.AllowedPaths` enforcement and `.git/**` / `.g8s/**` protection apply in-process on every mutation.

## 2. Setting Custom AGY Binary Path

If `agy` is installed in a non-standard directory, configure `AGY_BIN`:

```sh
export AGY_BIN="/usr/local/bin/agy"
# or
export AGY_BIN="$HOME/.gemini/antigravity-cli/bin/agy"
```

## 3. Declarative Model Adoption & Verification Workflow (DELTA-48)

The 4-step protocol for onboarding and verifying any adapter (including `agy`):

### Step 1 — Discover
```sh
# Enumerate live models from the provider
g8s providers discover --provider agy --json
```

### Step 2 — Declare
Add model entries with `family`, `cost_tier`, `status`, `effort_style` to `~/.config/g8s/providers.json` or `.g8s/agent-models.yml` (catalog_version: 3). Gemini 4 element series and orchestrator:
- `gemini-4-hydrogen-{low,medium,high,xhigh}` (economy)
- `gemini-4-argon-{low,medium,high}` (standard)
- `gemini-4-carbon-{low,medium,high}` (frontier)
- `gemini-pro-orchestrator` (frontier, `effort_style: none`)

Retain `gemini-3.8-*` as `deprecated`.

### Step 3 — Evaluate
```sh
# Audit catalog metadata and run conformance probes
g8s providers evaluate --provider agy --audit-catalog --json
g8s eval run --provider agy --model gemini-4-hydrogen-high --json
```

### Step 4 — Disjoint S3-A Blind-Verify
```sh
# Double-blind verification with disjoint-family verifier
g8s blind-verify --spec SPEC.md --invariants INVARIANTS.md --diff changes.diff \
  --model deep-coding --provider 9router --json
```

## 4. Submitting Tasks to AGY via CLI

```sh
g8s submit \
  --idempotency-key "agy-scan-001" \
  --prompt "Analyze project architecture and generate dependency graph" \
  --role "scout" \
  --permission "read_only" \
  --provider "agy" \
  --model "gemini-4-hydrogen-high"
```

Multi-adapter examples:
```sh
# 9router (api_call)
g8s submit --provider 9router --model reasoning-high --prompt "..."

# opencode (platform_dispatch)
g8s submit --provider opencode --model 9router/reasoning-high --prompt "..."

# codex (platform_dispatch)
g8s submit --provider codex --model gpt-5.4 --prompt "..."

# agy (platform_dispatch)
g8s submit --provider agy --model gemini-4-hydrogen-high --prompt "..."
```
