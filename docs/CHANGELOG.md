# Changelog

and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

The canonical release changelog lives at the repository root:

release history — a split-brain that broke the version-sync gate after the
v0.12.0 release (2026-09-27). The histories were consolidated into the root
changelog; the v0.2.0/v0.1.0 archive sections now live there too.
